# مركز حسين الاسدي - نظام إدارة كاونتر الزيوت والمخزون الذكي (PWA)

نظام سحابي وتطبيق ويب تقدمي (PWA) فائق السرعة مخصص لورش تبديل الزيوت، كاونترات المبيعات المباشرة، وحسابات المركبات والزبائن.

---

## 🚀 المميزات الرئيسية للمشروع

1. **واجهة استخدام صناعية داكنة (Dark Industrial Slate #0f172a / #1e293b)** مع لمسات العنبر البرتقالي (#f59e0b) والزمردي (#10b981)، متوافقة بالكامل مع الاتجاه من اليمين لليسار (`dir="rtl"`).
2. **إدارة السوائل والزيوت باللتر والكسور العشارية (Fractional Dispensing)**: خصم استهلاك الزيت بدقة (مثلاً: 4.4 لتر) من براميل أو عبوات الجملة تلقائياً.
3. **كاونتر تبديل الزيت السريع (Workshop POS)**:
   - بحث فوري برقم هاتف الزبون أو لوحة المركبة مع تعبئة تلقائية لبيانات المحرك وسعة الزيت السابقة.
   - أزرار القفز السريع للعداد القادم (+5000 كم، +7000 كم، +10000 كم).
   - توثيق ملاحظات الفني الميكانيكية (تبخير رنكات، فحص دهن الگير ATF، ماء الراديتر).
   - نظام تلقائي لنقاط الولاء (Loyalty Points).
4. **نظام البيع المباشر السريع (Direct Counter Sales)**: كاونتر كاش سريع للمواد والعبوات دون اشتراط إدخال بيانات سيارة أو عداد.
5. **ملف الزبون وكشف الديون (Customer Dossier & Debt Ledger)**:
   - كشف حساب فوري للأقساط والديون مع تسجيل سندات القبض.
   - محرك إرسال رسائل واتساب ذكي للتذكير بموعد الزيت أو المطالبة بالدين بنقرة واحدة.
6. **ملصق الزجاج وبوابة فحص الزبون بالـ QR Code**: صفحة عامة سريعة للهاتف تعرض آخر صيانة والعداد القادم مع أزرار خرائط Google والواتساب.
7. **تطبيق قابل للتثبيت (PWA)**: مزود بـ `manifest.json` و `Service Worker` مع دعم العمل دون اتصال وتثبيت فوري على شاشات الأجهزة واللوحيات.

---

## 🗄️ البنية البرمجية والملفات المنشأة

- `schema.sql`: مخطط قاعدة بيانات PostgreSQL متكامل مع مشغلات التحديث التلقائي للمخزون (`process_inventory_deduction`) واحتساب نقاط الولاء وكشف الحساب المالي.
- `public/manifest.json`: إعدادات الـ PWA باللغة العربية مع اختصارات الشاشة الرئيسية.
- `public/sw.js`: Service Worker للتخزين المؤقت والتشغيل أوفلاين.
- `src/app/page.tsx`: كاونتر تبديل الزيت الفوري مع تعبئة وحسابات العدادات.
- `src/app/customers/page.tsx`: ملف كشف حساب العميل وسجل الزيارات السابقة والواتساب.
- `src/app/direct-sales/page.tsx`: شاشة البيع المباشر السريع للمواد والعبوات.
- `src/app/inventory/page.tsx`: لوحة تحكم مخزون السوائل باللتر وتنبيهات النفاذ.
- `src/app/public/vehicle/[token]/page.tsx`: صفحة البوابة السريعة لملصق الزجاج (QR Windshield Card).
